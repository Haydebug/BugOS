The customisation update.

**Turn parts on and off.** New Features page: use the taskbar, File Explorer and Squiggle together or on their own. Turning one off puts back what it changed (the Mac Dock, Finder for folders, the screenshot shortcuts).

**Taskbar**
- Size (small, medium, large), centred or left icons
- Background: clear, blurred or solid, with opacity and any colour
- Floating rounded bar with adjustable corners
- Running-app mark: pill, dot, line or none
- Window previews on/off, and how fast they appear

**File Explorer**
- Folders open in File Explorer by default, now on macOS 26 too (it takes over Finder's window)
- Themes: Windows 11, Mica and Liquid Glass, with an optional glass tint
- Light, dark or automatic, with a dark app icon to match
- Change the new-window shortcut (⌥⌘E), where new windows open, reopening tabs, default folder view, extensions, hidden items, check boxes, navigation and preview panes

**Squiggle**
- Change every shortcut, add more than one, or remove them
- New shortcuts you can set: snip the whole screen, record an area
- Save folder, snip thumbnail, sound from the Mac and microphone, default pen colour and size

**Quick corner**
- Listed the way the fan looks, with System Settings on top
- New BugOS Settings shortcut
- Add any app with +

**Everything else**
- Accent colour for all of BugOS
- Updates from GitHub: BugOS checks once a day and installs new versions for you
- Restart a part from General if it ever gets stuck
- The app is now called BugOS
